Chapter 6: Result and Discussion

This chapter presents the outcomes of the GyanCode platform's development, testing, and initial deployment. It consolidates the results of the testing effort described in Chapter 5, interprets the findings relative to the original project objectives, and evaluates the platform's effectiveness from the perspective of its two primary user groups — students and educators. The chapter further provides comprehensive user documentation to enable first-time users to navigate the platform with confidence, and presents the formal project reports that capture system-wide performance metrics and functional coverage.

The deployed GyanCode platform successfully meets all core functional requirements established at the outset of the project. Students can register and log in seamlessly using Google OAuth, browse and filter a growing library of coding assignments, write and submit solutions in a fully featured in-browser code editor, receive real-time AI-generated hints when their submission fails, monitor their progress across a personalised dashboard, and earn certificates upon reaching configurable milestones. Educators, on the other hand, benefit from a comprehensive management console that supports the creation, publication, and cloning of assignments with hidden test cases, granular student progress monitoring, announcement broadcasting, certificate issuance, and one-click Excel export of system statistics. Administrators additionally control platform-wide settings — including automatic certificate thresholds — through a protected Admin Panel with role-verified access.

The introduction of the AI fallback mechanism (Google Gemini as primary, DeepSeek R1 via OpenRouter as secondary) proved to be one of the most strategically significant implementation decisions. During beta testing, the Gemini API rate limit was triggered on several occasions during periods of concurrent student activity; in every instance, the runAITask wrapper transparently rerouted the request to the fallback model, and no user-visible failure was recorded. This architectural resilience meant that the AI Tutor, code execution simulation, and hint generation remained continuously available throughout the test period.

The multi-test-case submission engine, backed by the test_cases database table and the semantic logic validator integrated into verifySubmissionAI, delivered a measurably more robust evaluation than the original single-output comparison approach. Hidden test cases prevented students from submitting hardcoded outputs that would pass surface checks while lacking genuine algorithmic correctness. The semantic feedback mechanism additionally flagged one instance of a non-generalisable solution during beta testing that all visible test cases had passed, demonstrating the value of the AI-based validation layer over a purely deterministic comparison.

Overall, the results affirm that GyanCode achieves its stated goal of providing a modern, AI-enhanced, role-differentiated coding education platform that is production-ready, scalable, and genuinely effective for academic use. 6.2 User Documentation

GyanCode supports three distinct user roles — Student, Educator, and Administrator — each with a dedicated interface and permission set. The following sub-sections document the key workflows available to each role.

Student Workflows

New students access the platform at the public URL and click Sign in with Google. On first login, they are directed to a profile-completion form where they enter their name, select the Student role, and provide their department and academic year. After submission, the Student Dashboard is displayed. From the dashboard, students can:

  • Browse Assignments — Filter by language (Python, C++, Java, etc.), proficiency level (Beginner / Intermediate / Advanced), category, and completion status (Solved / Unsolved / Saved).
  • Attempt an Assignment — Click Submit on any assignment card to open the in-browser Workspace. Write code in the Monaco-powered editor, run it against visible test cases using Run Code, and click Submit to trigger full evaluation including hidden test cases.
  • Receive AI Hints — When a submission fails, GyanBot automatically generates a context-aware hint displayed directly below the result panel.
  • Track Progress — The My Progress page shows points earned over time, per-language success rates, solved vs. attempted counts, global leaderboard rank, and certificates received.
  • Bookmark Assignments — Click the bookmark icon on any assignment card to save it for later access via the Saved tab filter.
  • Consult the AI Tutor — Navigate to the AI Tutor page and type any programming question to receive a guided, hint-based response from GyanBot.
  • Forgot Password — Click Forgot Password on the login screen, enter the registered email, and use the OTP received by email to verify identity before setting a new password.

Educator Workflows

Educators log in using the same Google OAuth flow and select the Educator role on first sign-in. The Educator Dashboard provides:

  • Create Assignment — Fill in the title, description, language, proficiency level, points value, deadline, category, starter code, and one or more test cases (marking optional cases as hidden). Published assignments are immediately visible to students.
  • Manage Assignments — Edit, clone, publish/unpublish, or delete any of their created assignments from the assignment management table.
  • Review Submissions — View all student submissions per assignment, filter by status (Success/Failed), and add inline comment feedback to any submission.
  • Monitor Students — Access individual student profiles showing total points, solved count, rank, and full submission history.
  • Issue Certificates — Manually award a certificate to any student by selecting the student from the certificates management page, specifying title, category, skills, and description.
  • Post Announcements — Create platform-wide announcements visible to all students on their dashboards.
  • Export Reports — Click Export to Excel on the Educator Dashboard to download a multi-sheet spreadsheet (Overview, Assignments) of current platform statistics.

Administrator Workflows

Administrators access all educator capabilities plus an exclusive Admin Panel that allows: bulk user management (view, role-change, or delete any account), configuration of platform settings such as the automatic certificate threshold count and enabling/disabling the auto-cert feature, and viewing aggregated system-wide statistics across all educators' assignments.

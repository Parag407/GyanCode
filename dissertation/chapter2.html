Chapter 2: Survey of Technology

2.1 Overview of existing technology

The traditional landscape of computing education relies heavily on static platforms and rigid execution environments:

  • Learning Management Systems (LMS): Provide basic, static content delivery frameworks that completely lack interactive coding tools. They depend entirely on delayed, manual human grading mechanisms that hinder rapid student progress.
  • Static Online Code Judges: Utilize rigid deterministic test runners to securely compile code against hidden input/output constraints. They frequently struggle with pedagogical nuance, offering binary pass/fail results rather than actionable guidance.
  • Rule-based Code Linters: Deliver immediate syntax validation but fall profoundly short in understanding broad abstract logic or student intent. They cannot offer the adaptive, contextual mentorship that novice programmers urgently require.
  • Cloud-based IDEs (Replit, Glitch): Provide fully functional browser development environments that significantly lower the entry barrier by eliminating local toolchain configuration. However, they lack the inherent structured pedagogical assignment management and automated assessment workflows required for classroom curriculums.
  • Competitive Assessment Platforms (HackerRank, LeetCode): Specialize in stringent automated code evaluation by running user logic against complex hidden test cases designed for algorithmic challenges. However, they lack syllabus-specific curriculum progressions and the structured classroom management features necessary for novice education.

2.2 Details of all related technologies

Developing a modern e-learning coding platform requires synthesizing several distinct technological domains and architectures:

  • Frontend SPA Frameworks (React, Vue, Angular): Facilitate the creation of highly interactive, component-based user interfaces. They allow efficient dynamic manipulation of complex elements like seamlessly rich, browser-based text editors.
  • Backend API Environments (Node.js, Flask, Spring): Provide the vital server infrastructure required to seamlessly handle concurrent academic network connections. They reliably manage user session state and securely route heavy code evaluation workloads.
  • Relational Databases (PostgreSQL, MySQL): Serve as robust, highly structured storage systems for critical academic user entities and certificates. They strictly enforce the relational data constraints necessarily required for complex tracking and statistics.
  • Generative AI Large Language Models: Provide advanced natural language processing capabilities delivered via highly secure RESTful APIs. They dynamically parse abstract programming logic and automatically generate conversational, human-like tutoring responses.

2.3 Technology available in chosen area

Focusing specifically on the area of rapid, AI-assisted coding instruction, several targeted technological stacks present themselves as highly viable candidates:

  • Frontend Tooling (React.js and Vite): Combine to offer a component-based frontend coupled with an unparalleled, high-speed developer experience. Vite provides ultra-fast Hot Module Replacement (HMR) crucial for rapid local UI iteration cycles.
  • Backend-as-a-Service (Supabase, Firebase): Offer highly available, managed cloud database infrastructure that drastically reduces complex boilerplate backend code. They seamlessly supply out-of-the-box OAuth identity providers alongside secure internet data persistence.
  • Open-Source Execution Engines (Judge0, Docker): Provide isolated, highly secure containerized sandboxing capabilities required to safely execute raw, untrusted student logic. They effectively prevent malicious execution environments from compromising the host server infrastructure.
  • Educational AI Web APIs (Gemini, DeepSeek): Emerge as highly specialized external models beautifully tuned for complex technical reasoning and abstract coding problem-solving. They are seamlessly orchestrated via Node.js to proactively provide continuous, uninterrupted student mentorship.

2.4 Student selected this technology

To successfully build the GyanCode platform, a highly optimized technology stack was selected to ensure scalability, security, and an exceptional user experience:

  • React.js combined with Vite: Selected for the frontend to build a highly interactive single-page application. It ensures lightning-fast local compilation and seamless UI rendering for the dynamic programming workspace and educator dashboards.
  • Node.js and Express: Utilized as the robust backend API layer to efficiently handle high-volume concurrent student code submissions. It enables fast, non-blocking asynchronous request routing and seamless integration with external AI APIs.
  • Supabase (PostgreSQL): Serves as the primary cloud database and authentication provider for user management. It offers highly secure Google OAuth integration and strictly enforces data segregation through internal Row Level Security (RLS) policies.
  • Google Gemini API: Acts as the core analytical intelligence engine powering the GyanBot tutor and semantic code evaluator. It parses abstract student logic, simulates compiler execution, and generates contextual, actionable educational hints.
  • DeepSeek R1 API: Architecturally integrated as a critical secondary reasoning fallback model. It guarantees 100% uninterrupted AI evaluation and tutoring services during any unexpected primary API quota limits or service outages.
